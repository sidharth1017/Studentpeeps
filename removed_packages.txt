Packages removed from requirements_v3.txt.

Uninstall these in the server virtualenv before or after deploying this code:

pip uninstall -y social-auth-app-django social-auth-core python3-openid requests-oauthlib oauthlib defusedxml PyJWT opencv-python pytesseract rapidfuzz fitz

Why each one was removed
- social-auth-app-django, social-auth-core: Google social login is no longer used.
- python3-openid, requests-oauthlib, oauthlib, defusedxml, PyJWT: only installed for social auth.
- opencv-python, pytesseract, rapidfuzz, fitz: only used by college ID card checks.

django-summernote stays installed. Attachments are hidden in admin. Policy pages and brand descriptions still use the editor.

Optional cleanup on the server, after a database backup
- Environment variables that settings.py no longer reads: SOCIAL_AUTH_GOOGLE_OAUTH2_KEY_PRODUCTION, SOCIAL_AUTH_GOOGLE_OAUTH2_SECRET_PRODUCTION, and the local SOCIAL_AUTH_GOOGLE_OAUTH2_KEY_LOCAL / SOCIAL_AUTH_GOOGLE_OAUTH2_SECRET_LOCAL pair if those exist.
- The tesseract system package, if it was installed only for ID card OCR.
- Unused tables the app no longer queries: accounts_v2_abandonedsignup, accounts_v2_unverified, accounts_v2_unverifiedidupload, accounts_v2_rejectedusers, and the social_auth_* tables. Do not drop accounts_v2_register. That table is the new signup list.
